# RU → EN Live Translator

Веб-приложение для почти мгновенного перевода **русской речи в английскую**. Оно умеет брать звук из:

- микрофона;
- вкладки браузера / демонстрации экрана (удобно для YouTube, стримов, видеозвонков);
- локального видеофайла.

Перевод возвращается одновременно как **английская речь** и **английские субтитры**. Также интерфейс показывает распознанный исходный текст.

## Как это работает

Браузер захватывает аудиодорожку и отправляет её через WebRTC в OpenAI Realtime Translation. Сервер нужен только для безопасного создания короткоживущего client secret — постоянный `OPENAI_API_KEY` в браузер не попадает.

Модель: `gpt-realtime-translate`  
Направление MVP: Russian → English (`en`)

## Требования

- Node.js 20+
- современный Chrome / Edge (рекомендуется для захвата звука вкладки)
- OpenAI API key с доступом к Realtime Translation

## Запуск

```bash
cp .env.example .env
```

В `.env`:

```env
OPENAI_API_KEY=sk-...
PORT=3000
```

Затем:

```bash
npm install
npm run dev
```

Откройте:

```text
http://localhost:3000
```

## Режимы

### 1. Микрофон

Нажмите **«Микрофон» → «Начать перевод»**, разрешите доступ к микрофону и говорите по-русски.

### 2. Видео / вкладка

Подходит для YouTube, онлайн-трансляций и видеозвонков.

1. Откройте источник видео в отдельной вкладке.
2. В приложении выберите **«Видео / вкладка»**.
3. Нажмите **«Начать перевод»**.
4. В системном окне выберите нужную вкладку и обязательно включите передачу звука вкладки.

### 3. Видео файл

Выберите локальный файл, затем нажмите **«Начать перевод»**. Видеоплеер запустится, его звук пойдёт одновременно на локальное воспроизведение и в переводчик.

## Что уже есть

- потоковый RU → EN перевод;
- английская озвучка;
- английские субтитры;
- исходная расшифровка;
- микрофон;
- звук вкладки/экрана;
- локальные видеофайлы;
- API-ключ только на сервере;
- адаптивный интерфейс.

## Ограничения MVP

- Это перевод **аудиодорожки** видео; изображение видео не анализируется и не изменяется.
- Для режима «Видео / вкладка» браузер/ОС должны разрешать передачу системного звука.
- Для двустороннего звонка с переводом обоим участникам нужны две независимые translation-сессии (по одной на каждое направление).
- Качество имён, чисел и терминов стоит проверять на данных вашей предметной области.

```text
       │
       ▼

       │                                  │
       │                                  ├── translated audio
       │                                  └── transcript deltas
       ▼
Browser UI: EN audio + RU/EN subtitles

Server: POST /api/session → creates short-lived Realtime client secret
```
