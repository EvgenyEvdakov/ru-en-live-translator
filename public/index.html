Важно: «идентичный» голос технически не гарантируется. Модель клонирует тембр и часть манеры речи; качество выше на чистом голосе без музыки и посторонних людей.

Задержка: перевод идёт по коротким фразам. На NVIDIA GPU это близко к реальному времени; на CPU клонирование голоса может заметно отставать.

Для вкладки браузера включите «Поделиться аудио вкладки». Для микрофона лучше использовать наушники, чтобы перевод не попадал обратно в микрофон.
